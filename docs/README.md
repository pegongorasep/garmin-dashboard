# Documentos

Vigentes:

- `PLAN_LIMPIEZA.md`: plan de limpieza del código y los docs (en curso).
- `PLAN_ANIMACIONES.md`: estados vacíos, primeros pasos y animaciones (fases A1 a A5).
- `DUDAS.md`: decisiones y hallazgos por versión.
- `REQUISITOS_V5.md` y `PLAN_V5.md`: la web Ahí la Llevas (cuentas, repos-tubo, coach).
- `INVESTIGACION_PLANES.md`: reglas de seguridad y base científica del motor de planes v6.
- `REQUISITOS_PLANES.md` y `PLAN_PLANES.md`: planes fijos, repetir o retomar, carreras de paso.
- `REQUISITOS_CONEXION.md` y `PLAN_CONEXION.md`: conexión con Garmin (GitHub App) y sincronización.
- `REQUISITOS_ENTRADA.md` y `PLAN_ENTRADA.md`: entrada libre y registro a mano.
- `PLAN_SIN_PLAN.md`: modo «Sin plan».
- `PLAN_GRUPOS.md`: grupos de amigos y perfil.
- `PLAN_I18N.md`: español e inglés con catálogo de textos.
- `PLAN_DISENO.md`: sistema de diseño «Anillo».
- `PLAN_LOGIN.md`: login con Google, código por correo e invitación.
- `PLAN_APRENDE.md` y `PLAN_CAMBIOS.md`: sección «Aprende» y pestaña de cambios con resumen de la IA.

`historial/` son planes y requisitos ya ejecutados (v1 a v4.5, «solo cuerpo»); se guardan solo como registro.
